# InfoPath - Panduan Jurusan Informatika

Tugas web design kelompok 3 berupa landing page edukasi untuk siswa SMA/SMK
yang ingin mengenal jurusan Informatika, prospek kerja, strategi belajar, dan
tips masuk kuliah.

## Teknologi

- HTML
- CSS
- JavaScript

Proyek ini tidak menggunakan framework atau library frontend.

## Fitur Utama

- Navigasi sticky dengan hamburger menu untuk tampilan mobile.
- Hero section dengan gambar utama dan tombol menuju materi.
- Informasi jurusan Informatika dalam bentuk card artikel.
- Daftar prospek kerja lulusan Informatika.
- Strategi belajar sejak bangku sekolah.
- Tips masuk jurusan Informatika.
- Bagian referensi materi.
- Gambar utama disimpan lokal di folder `assets/images`.

## Struktur Folder

```text
Project-WebDesain/
  README.md
  index.html
  assets/
    images/
  css/
    style.css
  js/
    script.js

```

## Cara Menjalankan

Buka file `index.html` menggunakan browser.

## Catatan

- Halaman dapat berjalan tanpa server karena hanya memakai HTML, CSS, dan
  JavaScript dasar.
- Gambar konten sudah tersedia secara lokal di folder `assets/images`.
- Font masih menggunakan Google Fonts, sehingga tampilan font terbaik tetap
  membutuhkan koneksi internet.
- Kisaran gaji pada halaman bersifat estimasi untuk bahan pembelajaran dan dapat
  berubah sesuai wilayah, pengalaman, serta kondisi industri.
